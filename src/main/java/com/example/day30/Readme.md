# 分发糖果
得分高的孩子必须比邻居得到更多的糖果
直接两次遍历就行,第一次yi ci 遍历的时候,将当前孩子得分高的孩子糖果数 + 1,如果当前孩子得分比前一个孩子得分高,则将当前孩子糖果数 + 1,
不过要注意从右向左遍历时条件判断需改变
candies[i] = max(candies[i - 1] + 1, candies[i])
