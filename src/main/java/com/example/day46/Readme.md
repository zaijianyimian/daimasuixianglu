# 两个不同的子序列：
两个子序列都可以删，
dp[i][j]以i- 1为结尾，j- 1为结尾的子序列个数
dp[i][j] = dp[i - 1][j - 1]
dp[i - 1][j - 1] 不考虑这两个元素，
else: 
dp[i][j] = min(dp[i - 1][j],dp[i][j - 1]) + 1
dp[i - 1][j - 1] = dp[i - 1][j] + 1 = dp[i][j - 1] + 1
dp[i - 1][j] 删除i- 1的元素，
dp[i][j - 1] 删除j- 1的元素
